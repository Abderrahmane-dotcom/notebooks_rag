## Contenu

- **rag1_application_du_rag_done.ipynb**
  - Présente une application RAG (Retrieval-Augmented Generation).
  - Contient l'extraction de données, l'indexation, la logique de requêtes et des exemples d'exécution montrant les réponses générées.

- **SemanticSearch_ELK_done.ipynb**
  - Démonstration d'une recherche sémantique en utilisant la pile ELK (Elasticsearch / Logstash / Kibana) ou des composants similaires.
  - Montre comment indexer des documents, exécuter des requêtes sémantiques et visualiser les résultats.
